Cara Install di HP

Aplikasi Sudah Online (GitHub Pages)

Karena sudah di-host di GitHub dengan protokol HTTPS, tombol install otomatis akan berfungsi di browser HP Anda.

Pengguna Android (Chrome):

Ketuk titik tiga (⋮) di sudut kanan atas Chrome, lalu pilih "Tambahkan ke Layar Utama" atau "Install Aplikasi".

Pengguna iPhone (Safari):

Ketuk ikon tombol Bagikan (Share) di bagian bawah layar Safari, lalu pilih "Add to Home Screen".
